## What these files also show (and the rules now say otherwise)

- Some include **numbers** ("45-Minute", "45.rhad.agency") and **small label strips** on objects. These are composited layers on finished posters. On carousel slides the no-numbers rule still applies: write "Arrange a business review" on the slide and keep the duration in the caption
- The carousel cover shows a CTA line. Inner slides use the icon only
- The shared guide's stricter rule is kept: **never display slide numbers, counters, asset IDs or production labels**
