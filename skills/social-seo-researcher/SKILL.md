# Social SEO Researcher

Social platforms are search engines now. The job: make every post findable by the people searching for what the brand offers - without making it read like keyword soup.

## Step 1: Load or build the brand profile

Every skill in this set runs off the same brand profile. Look for one first:

1. Check project knowledge, custom instructions, memory and conversation files for a "Brand Profile" block or `brand-profile.md`
2. Check earlier in this conversation
3. Use any brand details in the user's request

If none exists, ask in a single numbered message: (1) brand name and what it does, (2) audience, (3) tone in three words plus a style reference, (4) platforms, (5) standard CTAs, (6) banned words and emoji rules. If answers are partial, state assumptions and continue.

After the first run, persist the profile yourself - don't put the burden on the user. In order of preference: (1) if memory is available, save the filled-in Brand Profile block to memory; (2) if you can write files in this project or workspace, save it as `brand-profile.md`. Then confirm in one line where it's saved ("Brand profile saved - none of these skills will ask again"). Only if you can't persist it anywhere, show the block and ask the user to paste it into their project instructions.

```
## Brand Profile
- Brand: [name] - [one-line description]
- Audience: [who]
- Tone: [three words] (style reference: [example])
- Platforms: [list]
- CTAs: [standard asks]
- Banned: [words/phrases] | Emoji: [rule]
```

## Step 2: Understand the content and the searcher

Establish: the topic of the post/video, the platform(s), and crucially **what the target audience would type to find this**. Think in their words, not the brand's - people search "why is my engagement dropping", not "engagement diagnostics". List 3–5 plausible search phrases before picking any tags.

If web search is available, use it to sanity-check which terms and hashtags are currently active for this topic. If it isn't, reason from principles, and say plainly that tag volumes should be spot-checked in the platform's own search bar (typing a term into TikTok/Instagram search shows live volume and suggestions - recommend the user does this 30-second check).

## Step 3: Build the deliverables per platform

**Hashtag sets (Instagram, TikTok)** - a tiered set, because all-broad means invisible and all-niche means tiny reach:

- 1–2 **broad** tags (large, category-level)
- 2–3 **mid** tags (the topic itself, where the realistic ranking chance lives)
- 2–3 **niche** tags (specific community or long-tail phrases, plus one branded tag if the profile has one)

For each tag, one short note on why it's there. Total 5–8 - never 30. Flag any tag that looks high-volume but is actually flooded with unrelated content.

**Video SEO (TikTok, Reels, Shorts)** - platforms transcribe audio and read on-screen text:

- The exact keyword phrase to SAY in the first 3 seconds
- The phrase to show as on-screen text
- A caption line that uses the keyword naturally

**YouTube** - title (under 60 characters, keyword early, curiosity intact), description (first 2 lines carry the keyword and the click reason, then 100–200 words of natural detail), and 5–10 tags.

**LinkedIn** - 1–3 topical hashtags only, plus the keyword worked into the first 210 characters of the post, which is what both LinkedIn search and Google index hardest.

**Alt text** - one or two sentences describing the image for a screen reader user, with the keyword included only when it accurately describes the image. Accessibility first, SEO second; stuffed alt text fails both.

## Step 4: Quality loop - never deliver a first draft

Check before delivering, and fix anything that fails:

1. Every recommended term maps to one of the searcher phrases from Step 2
2. The tier mix is honest - no pretending a mega-tag is winnable
3. Captions and titles still read like a human wrote them (read aloud test)
4. Nothing violates the brand profile's banned list
5. Alt text describes the actual image

## Step 5: Deliver

Group output by platform, ready to copy and paste. Lead with the single most important keyword phrase for the piece, so the user knows the spine of the whole set. Where claims about tag performance are assumptions rather than verified, label them - this skill's credibility depends on not guessing silently.
